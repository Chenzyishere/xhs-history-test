# 你最像哪个历史人物？

一个面向小红书的移动端人格测试 H5：12 道题，测出你灵魂深处最像的 16 位历史人物之一，并可生成 1080×1440 的分享卡供用户晒图传播。

纯静态实现，无框架、无构建、无后端依赖，双击 `index.html` 即可运行。

## 功能

- 密码解锁页 → 开始页 → 12 道题 → 结果页，完整流程
- 支持「上一题 / 下一题」，可回退修改答案，分数实时重算
- 答题进度实时存 `sessionStorage`，刷新页面不丢答案
- 结果页四维雷达图，直观展示人格分布
- 一键复制晒单文案（含话题标签），降低用户发笔记门槛
- 结果卡保存：iOS 走长按保存浮层（Safari 不支持直接下载），其余浏览器直接下载 PNG
- 四维人格模型匹配 16 位历史人物
- Canvas 生成竖版分享卡（人物名 + 印章 + 金句 + 3 个相似点 + 人生建议），一键下载 PNG

## 部署（GitHub Pages）

1. 新建 GitHub 仓库（Public），把本目录推上去
2. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`
3. 得到 `https://用户名.github.io/仓库名/` 的访问地址
4. 绑定自定义域名：Settings → Pages → Custom domain 填域名，再到域名服务商加 DNS 记录（子域名 CNAME 到 `用户名.github.io`，裸域加 4 条 A 记录）

## 内容数据（核心，维护看这里）

所有内容都在 [js/data.js](js/data.js)，改产品不用动其他文件。

### 解锁（unlock）

```js
unlock: {
  masterCode: "9900",              // 主密码，你自己测试用，永久有效
  salt: "LSRW-2026-xhs-history",   // 校验盐值
  prefix: "LSRW",                  // 验证码前缀
  hint: "购买后获取验证码，输入即可开始",
}
```

打开链接先输验证码才能进入测试。验证通过后会在 `localStorage` 记一个标记，同一台设备不用重复输入。

验证码格式：`LSRW` + 6 位随机字符 + 1 位校验位，例如 `LSRW7K2M9X3`。

**发码方式**：打开 [tools/generate-codes.html](tools/generate-codes.html)（本地文件，已加入 `.gitignore`，不会上传），填入与 `data.js` 一致的 salt 和 prefix，批量生成并下载 txt。卖一单发一个码。

**注意**：`tools/` 目录不会被推到 GitHub，只在你本地。换电脑时记得单独备份。

### 四维显示名（dimensions）

```js
dimensions: [
  { pos: "入世", neg: "出世" },
  { pos: "刚", neg: "柔" },
  { pos: "燃", neg: "佛" },
  { pos: "破格", neg: "守序" }
]
```

雷达图的四个轴，`pos` 是正向极（画在轴端），`neg` 是反向极（显示在下方标签里）。顺序必须与计分的四维顺序一致。

### 晒单文案（share）

```js
share: {
  template: "我测出来是{name}😆 {title}\n\n「{tagline}」\n\n12 道题测出你灵魂深处最像哪位历史人物，你也来试试？\n\n#历史人物 #性格测试 #趣味测试"
}
```

用户点「复制晒单文案」时复制的内容。可用占位符：`{name}` `{title}` `{tagline}` `{advice}` `{brand}`。

### 人物（figures 数组）

```js
{
  id: "sushi",          // 唯一标识
  name: "苏轼",          // 人物名
  title: "反内耗大师",    // 定调标签
  tagline: "被贬到哪，就在哪吃好喝好",  // 金句（结果卡主文案）
  seal: "松弛",          // 印章二字
  color: "#b5562f",     // 结果页专属色
  vector: [0.2, -0.6, -0.2, 0.4],  // 四维坐标（-1 ~ 1）
  traits: ["...", "...", "..."],   // 3 个相似点
  advice: "..."          // 人生建议
}
```

### 题目（questions 数组）

```js
{
  id: "q1",
  text: "周一早上醒来，你脑子里的第一个念头是？",
  options: [
    { text: "这周有什么硬仗要打", effect: [1, 0, 0, 0] },  // 选中后给四维的加分
    { text: "这班是非上不可吗", effect: [-1, 0, 0, 0] }
  ]
}
```

## 四维人格模型与计分

四个维度，每题选项通过 `effect` 数组给对应维度加分（`+1` / `-1` / `0`）：

| 下标 | 维度 | 正极 | 负极 |
|---|---|---|---|
| 0 | D1 | 入世 | 出世 |
| 1 | D2 | 刚 | 柔 |
| 2 | D3 | 燃（大义/责任） | 佛（自我/淡泊） |
| 3 | D4 | 破格 | 守序 |

计分流程：

1. 每维 3 题，得分范围 `-3 ~ +3`
2. 提交时从答案累计四维得分，除以 3 归一化到 `-1 ~ 1`
3. 与 16 个人物的 `vector` 计算**欧氏距离**，取最近者为结果

## 如何换题材

这套代码是「测试 H5 模板」。要换一个题材（历史人物 → 明星 / CP / 古风 / 二次元 / 职场……），只需：

1. 改 [js/data.js](js/data.js) 的 `figures`：换掉人物名、文案、`vector`
2. 改 `questions`：换题目和选项文案，`effect` 保持四维结构不变
3. 改 [index.html](index.html) 和 `data.js` 里的标题文案

计分引擎、页面、分享卡全部复用，不需要动 [js/app.js](js/app.js)。
