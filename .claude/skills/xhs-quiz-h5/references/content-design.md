# 内容设计：让结果"像自己"

这个产品成败的 80% 在这一页。代码只是容器。

## 一、选人物

### 判断标准

不要按历史地位选，按**当代情绪**选。检验方法：说出这个人物，能不能立刻接上一个现代人正在焦虑的词？

| 人物 | 能挂上的当代情绪 |
|---|---|
| 苏轼 | 反内耗、松弛感、被贬了还能吃好喝好 |
| 李白 | 精神状态领先、不服就干 |
| 曾国藩 | 笨人逆袭、自律自救 |
| 嘉靖 | 反 PUA、边界感、摸鱼哲学 |
| 武则天 | 大女主、规则改写 |
| 王安石 | 理想主义打工人 |
| 陶渊明 | 裸辞、躺平、不过度竞争 |
| 王阳明 | 知行合一、破内耗 |

### 数量与分布

- **16 个**最合适：够多显得有内容，又不至于让人挑花眼
- 正向人物和"反向/松弛"人物要**各占一半**，否则所有人都测出同一类型
- 避免选过于冷门的人物（用户不认识 = 没有共鸣），也避免选过于脸谱化的（没意思）

## 二、四维模型

### 为什么用双极维度

不要用"责任心强/弱"这种单向维度。单向维度会导致**中间态不可达**，一部分人物永远匹配不到。

双极维度让每个人物落在四维空间的某个位置，用户也在同一空间里，算欧氏距离取最近。

### 维度命名

用**叙事型**命名，不要用心理学术语：

| ✅ 好 | ❌ 差 |
|---|---|
| 入世 / 出世 | 外向性高 / 低 |
| 刚 / 柔 | 宜人性 |
| 燃 / 佛 | 尽责性 |
| 破格 / 守序 | 开放性 |

### 示例四维（历史人物版）

```
D1  入世(+) / 出世(-)      要不要在世间做出一番事
D2  刚(+)   / 柔(-)        遇事硬碰硬还是圆融化解
D3  燃(+)   / 佛(-)        被大义责任驱动还是忠于自我
D4  破格(+) / 守序(-)      打破规则还是遵守规则
```

## 三、写题目

### 唯一原则：具体，有画面感

```
✅ 同事在会上抢了你的功劳，你会？
   A 当场点破，寸步不让
   B 私下委婉拿回来
   C 记下来，以后再算
   D 算了，不值当

❌ 我倾向于在冲突中表达自己的立场
   A 非常同意  B 同意  C 不同意  D 非常不同意
```

第二种是心理量表，用户做起来像填问卷，做完没有分享欲。

### 结构要求

- **12 题**，每题 4 个选项（3 个太少不够分化，5 个太多开始烦躁）
- 每题只影响 **1 个维度**（`effect` 数组只有一位非零），这样维度之间不互相污染
- **每个维度 3 道题**，得分范围 -3 ~ +3
- 选项要有**真实的两难**，不要有明显的"正确答案"

### 维度覆盖检查

```
D1: q1, q5, q9
D2: q3, q7, q11
D3: q4, q6, q10
D4: q2, q8, q12
```

如果某个维度只有 1-2 道题，得分会集中在少数几个值上，匹配精度下降。

## 四、写结果文案

每个人物四个字段，缺一不可：

| 字段 | 作用 | 长度 | 示例 |
|---|---|---|---|
| `title` | 定调标签，一眼记住 | 4–6 字 | 反内耗大师 |
| `tagline` | 金句，可截图传播 | 10–16 字 | 被贬到哪，就在哪吃好喝好 |
| `traits` | 3 个相似点，制造"被看穿"感 | 每条 12–20 字 | 天生乐观，再难的日子都能过出滋味 |
| `advice` | 人生建议，给情绪价值 | 15–25 字 | 你的松弛感就是你的超能力 |

### 写作要点

- **第二人称"你"**，不要用"该类型的人"
- **写具体行为，不写抽象性格**。"该吃吃该睡睡"比"心态积极"有画面感
- **带一点冒犯或自嘲**，纯夸的文案没人转发
- **advice 要给出出路**，不要只描述问题

### 自检

写完念一遍，问自己：

1. 这句话像不像我朋友会发给我的？
2. 我会不会截图发给别人说"这就是我"？
3. 如果测出来是这个，我会失望吗？（如果会，说明这个人物的文案没写好，不是人物选错了）

## 五、验证人物可达性

**上线前必做。** 计分空间是离散的，粗暴设计的向量会导致部分人物永远匹配不到。

### 快速验证方法

把每个维度的可达值列出来，再看每个人物的向量落点：

```
每个维度的可达归一化值（12 题版本，每维 3 题）：
  若 3 题都是 ±1：       {-1, -1/3, 1/3, 1}   ← 只有 4 档，中间态不可达
  若有题目含 0 分选项：   {-1, -2/3, -1/3, 0, 1/3, 2/3, 1}

可达点总数 = 各维度档位数相乘
16 个人物要全部能赢，每个人物附近必须有足够近的可达点
```

### 更强的做法

写个脚本穷举所有可达组合，统计每个人物被匹配的次数：

```js
// 上线前跑一次，确认 16 个人物都出现
const reachable = new Set();
// 枚举所有答案组合 → 算分 → match() → 记录人物 id
// 若某个 id 从未出现，调整它的 vector
```

**如果某个人物永远测不出来，它的文案写得再好也是白写。**

## 六、晒单文案

用户测完想发，但不知道写什么。给他现成的，转化率明显提升。

模板要素：

```
我测出来是{name}😆 {title}

「{tagline}」

12 道题测出你灵魂深处最像哪位历史人物，你也来试试？

#历史人物 #性格测试 #趣味测试
```

要点：
- 第一人称，带一点得意或自嘲
- 保留金句，这是最容易被转发的部分
- 明确 CTA："你也来试试"
- 带 3–5 个话题标签
