# 内容运营与推流

产品做出来之后，怎么把它推出去。这一篇覆盖：标题套路、硬广软文配比、发帖节奏、商品配图。

## 一、硬广 vs 软文：两条腿走路

| 类型 | 目的 | 挂商品 | 比例（新手期） |
|---|---|---|---|
| **硬广** | 转化、成交 | 挂 | 1 |
| **软文** | 养号、涨粉、埋兴趣 | 不挂 | 2 |

**核心逻辑**：纯硬广会被判营销号限流。软文提供价值、养号涨粉，硬广负责成交。软文不提测试，只讲"历史人物的性格/精神状态"，让读者自然产生"那我像谁"的好奇——这份好奇最终导向测试。

软文的三个承接钩子：
1. 主页承接（看完软文点进主页看到硬广）
2. 话题标签（软文也带 `#性格测试` 这类标签，顺着标签找到硬广）
3. 评论区引导（有人共鸣时回"可以测测看"，但**正文里绝不推测试**）

## 二、标题套路（从竞品拆解）

竞品爆款标题举例：

- 「你这种性格，历史上早就有人替你走完一生」
- 「你的创作基因来自哪位天才作家？」

**共同公式：第二人称 + 身份/命运暗示 + 悬念未完成**

- "你这种性格" → 直接对读者说话，制造"说的是我"
- "历史上有人替你走完一生" → 勾起好奇心：谁？怎么走的？
- 结尾留白 → 逼人点进去看全文

### 四类标题

| 类型 | 模板 | 示例 |
|---|---|---|
| 悬念型 | 不剧透，勾好奇 | 你这种性格，历史上早就有人替你走完一生 |
| 结果型 | 剧透一个，勾起对比 | 我是苏轼，你是李白还是嘉靖？ |
| 痛点型 | 精准戳人群 | 内耗的人，都测出了同一个历史人物 |
| 身份认同型 | 给身份标签 | 你的灵魂，历史上是哪位大人物？ |

**新手先主攻悬念型**：开放式问题好奇心驱动力最强，点击率最高。

## 三、硬广发帖节奏

- **每天 1–2 条，隔天发**，别一天 3 条以上（判刷屏）
- **黄金时段**：中午 12–13 点、晚上 19–22 点
- **每条正文末尾留互动钩子**（"评论区告诉我你测出谁"），评论数决定推流
- **发完 15–30 分钟守评论区**，每条都回，回得像真人

### 正文模板

```
你有没有发现，[共鸣点]？

[测试结果式陈述，像在说自己]

[一句引导]

评论区告诉我你测出谁👇
```

## 四、软文方法论

软文不推测试、不挂商品，只讲历史人物的性格/精神状态，埋"我像谁"的钩子。

### 三类软文

1. **反差知识型**：历史人物的冷知识/反差萌（"苏轼被贬了一辈子，却活成了最会生活的人"）
2. **共鸣型**：历史人物 = 当代打工人嘴替（"一千多年前，陶渊明就替我裸辞了"）
3. **观点型**：一个观点 + 历史人物佐证（"古人的精神状态，领先我们几百年"）

### 软文写作要点

- 口语化、第一人称、像真人聊天，别写成科普
- 每条聚焦**一个历史人物 + 一个当代情绪**（苏轼→反内耗、陶渊明→裸辞、嘉靖→摸鱼、武则天→大女主……）
- 正文 4–6 行，有画面感、有共鸣点
- 结尾不推测试，留一个让人想评论的点

### 软文选题库（历史人物 × 当代情绪）

| 人物 | 情绪 | 角度 |
|---|---|---|
| 苏轼 | 反内耗 | 被贬还研究美食 |
| 陶渊明 | 裸辞 | 不为五斗米折腰 |
| 李白 | 自由 | 被开除反而更爽 |
| 曾国藩 | 自律/普通人 | 笨人逆袭 |
| 嘉靖 | 摸鱼/反PUA | 不上朝也掌控朝堂 |
| 武则天 | 大女主 | 踩碎"女人不能当皇帝" |
| 王安石 | 理想主义 | 明知不可为而为之 |
| 曹操 | 不内耗 | 干就完了 |
| 李煜 | 文艺/敏感 | 被皇位耽误的词人 |
| 王阳明 | 修心 | 龙场悟道破内耗 |
| 范仲淹 | 责任感 | 先忧后乐 |

## 五、商品配图体系

个人售卖的商品详情页，7 张图的分工：

| 顺序 | 图 | 作用 |
|---|---|---|
| 1 | 主图（红底大字报） | 吸引点击购买 |
| 2 | 卖点图（测完得到什么） | 说清价值 |
| 3–6 | 结果卡样张 × 4 | 展示"结果长这样"，降低顾虑 |
| 7 | 使用说明（3 步） | 告诉买家怎么用 |

结果卡样张选 4 个**类型差异大**的人物（如反内耗/狂放/大女主/裸辞），让买家看到"测出来的人很多样"，降低"会不会很无聊"的顾虑。

### 配图生成

两种方式（见 `tools/`）：

1. **HTML 工具**（`product-images.html`）：打开 → 预览 → 手动下载 PNG，适合临时改
2. **Node 脚本**（`generate-images.js`）：`npm install && npm run images` 直接批量出 PNG 到 `images/` 文件夹，适合批量

设计统一中式大字报风格：宣纸米色底 + 朱砂红 + 印章 + 宋体大字。

## 六、两套图的分工（别混）

| 工具 | 产物 | 用途 |
|---|---|---|
| `cover-maker.html` | 封面 | **笔记封面**（引流） |
| `product-images.html` / `generate-images.js` | 商品图 | **商品配图**（成交） |

笔记把人引过来，商品详情把人转化掉，两套图各司其职。

## 七、定时发送

小红书个人号无原生定时功能，需第三方工具。备好内容后按天排期：

- 每天 3 条（软文为主），早/午/晚各一条，错开整点 20 分钟以上
- 硬广穿插在软文之间，不连续发硬广
- 4 天后看哪条互动最高，那个方向就是账号人设，后续多写

## 八、观察指标

| 指标 | 看什么 |
|---|---|
| 软文互动（赞/藏/评） | 哪个情绪方向最戳人 → 定账号人设 |
| 硬广点击/成交 | 哪类标题转化高 |
| 评论质量 | "我也是"这种共鸣评论越多，人设越准 |
